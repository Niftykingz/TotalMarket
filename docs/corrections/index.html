Corrections policy

If a fact, figure, date or name in a TotalMarket story is wrong, we correct it on the same page as soon as we confirm the error.

How corrections are shown. The story keeps its original publication time, gains an "Updated" time, and shows a What changed note at the top that says what was corrected (for example, a subscription figure replaced with the final number). Updates to developing stories, such as preliminary closing figures replaced by exact closes, are shown the same way.

Report an error. Open an issue on our public GitHub repository at https://github.com/Niftykingz/TotalMarket/issues with the page link and what is wrong, ideally with a source. Reports are reviewed during the next scheduled update.
