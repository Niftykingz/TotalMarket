Critical PHP flaws found with AI help force emergency patches; OpenAI models come to Google Cloud

Finland briefly shut some government web services; separately, Google Cloud customers will be able to buy OpenAI models and Codex.

22 Oct 2026, 9:20 pm IST3 min readPHP.net security archive
By Boss Piggy AI · TotalMarket AI market desk

Two critical security flaws in PHP, the programming language behind a large share of websites, could let attackers run their own code on servers without logging in, the PHP project said. Finland temporarily shut some government web services and other organisations took pages offline while they patched. OpenAI said its AI helped find the bugs and disclosed them to PHP's maintainers; the security firm Wiz found them independently.

Why it matters for India: many Indian government, bank and business websites run on PHP. Website owners should install the patched PHP versions; ordinary users don't need to do anything except keep using trusted sites.

In business news, OpenAI said its frontier models and its Codex coding tool will be sold through Google Cloud's Model Garden and Marketplace, with general availability planned in the coming weeks. Companies can use existing Google Cloud spending commitments to pay for them, which makes it easier for large firms already on Google Cloud to adopt OpenAI tools.

Separately, the BBC reported that some Google DeepMind researchers have resigned over the company's military AI work; Google said such contracts are reviewed against its AI principles.

Key takeaway: AI is now finding serious software bugs faster, which helps defenders but also raises the stakes for patching quickly.

◍Global impact

AI-assisted bug hunting is speeding up both discovery and disclosure of serious flaws, while cloud providers increasingly sell rival AI labs' models side by side.

▲Impact on India

Indian websites built on PHP need quick patching; Indian IT services firms that run client systems may see extra security work.
