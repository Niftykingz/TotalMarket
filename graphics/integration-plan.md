# Approved visual direction — production integration plan

Approval received 2026-10-22 for the **design direction**. This does not approve a merge, publication of third-party marks, or spending.

## Actual site architecture
- The website is generated by `build.py` into `docs/` (GitHub Pages serves `main/docs`).
- Existing production cover generation is in `covers.py` (Pillow), not the static HTML gallery.
- `art.py` and story JSON supply category, symbol and company metadata.
- New templates must be integrated into this Python cover pipeline, not treated as production by copying `graphics/preview.html`.

## Work sequence
1. Implement deterministic selection of diverse original cover compositions in `covers.py`, preserving current output dimensions, OG variants and existing category coverage. Avoid fake market data and repeated candle-only graphics.
2. Add a test that samples real story metadata and verifies cover generation without changing live `docs/`.
3. Build a safe company-logo resolver from `data/company-logos.json`: only approved records with original local assets; retain source file bytes and aspect ratio. No resizing of stored originals. Use proportionate display fitting only.
4. Source official assets for the 15-company queue, review each mark's usage terms, then add only authorized files. Pending marks show a neutral ticker badge, not an imitation.
5. Generate a local comparison preview and obtain explicit merge/deployment approval before changing `main` or `docs/`.

## Quality gates
- All source graphics created by TotalMarket; verified figures only, with attribution and as-of date.
- Logo originals preserved unchanged; SVG security review before use.
- No invented numbers, unlicensed photographs, forced square logos or trademark redesigns.
- Existing production covers and site layout must remain functional.
