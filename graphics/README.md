# TotalMarket Graphics Kit — initial implementation

This is an editorial graphics kit, not a replacement for existing live page components.

Open `graphics/preview.html` locally to preview six responsive story-card templates. The kit uses original SVG/CSS graphics and sample-only content. No generated asset represents an actual market chart, official logo, or current financial result.

The accompanying `graphics/graphics.css` provides reusable visual patterns for market movements, earnings, AI, policy, IPOs, and commodities. The templates can later be wired to verified article data. Do not publish sample metrics as live information.

Company logos remain in the separate `logos/` registry pipeline. Only official, verified, rights-reviewed PNGs should be added there. No third-party logos have been uploaded in this change.
